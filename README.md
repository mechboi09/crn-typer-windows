# CRN typer for Windows

**[Download CRN typer.exe](https://github.com/mechboi09/crn-typer-windows/raw/refs/heads/main/download/CRN%20typer.exe)**

## How to use

1. Close any older CRN typer apps and open **CRN typer.exe**.
2. Enter up to **seven CRNs** in each option.
3. Click the first empty CRN box in your browser.
4. Press **F1–F4** for the matching option.
5. Review Summary, then press **Submit** yourself.

## Editing

- Paste a list directly into a box to fill that box and those below it. Separate CRNs with spaces, commas or new lines.
- Press **Ctrl+A once** to select one CRN, or **twice quickly** to select the column.
- Copy, Cut, Paste and Delete work on the selected column. Clearing returns to its first box.
- **Closing the app clears your CRNs.**

## Modes

**Fast is the default.** Use the switch to change modes, or open **Tips** for the notes.

| Normal | Fast |
| --- | --- |
| 200 ms | 1 ms |

**Escape** cancels; switching windows also stops a run. Keep the correct browser tab and field focused, and review the result in Summary.
